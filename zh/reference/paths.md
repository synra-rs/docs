# 数据位置

应用选择平台的数据和缓存根目录，CLI/daemon 可以使用自己配置的目录。
不要假定另行运行的 daemon 与应用共享状态。

## 确认当前配置目录

应用使用 Tauri 为标识符 `com.synra.app` 提供的数据与缓存目录。
Android 使用应用私有存储，隔离的开发配置使用不同标识符，因此根目录也不同。

使用 CLI/daemon 时，始终保持数据目录一致，包括 `SYNRA_DATA_DIR` 覆盖。
准确参数以对应二进制帮助为准，不要把 daemon 参数直接传给 GUI。

## 数据布局

| 相对路径 | 内容 |
| --- | --- |
| `kernel.db` | SQLite 设备、插件状态、配置和任务记录 |
| `config.json` | 启动配置 |
| `plugins/` | 已安装插件文件 |
| `plugin-data/` | 独立的各插件数据沙箱 |
| `inbox/` | 接收文件与包 |
| `logs/` | 宿主日志文件 |
| `logs/crash/` | 崩溃记录 |

版本更新替换插件文件，无需删除 plugin-data。
配对记录保存在数据库中，当前配对不依赖共享加密密钥。

## 缓存布局

| 相对路径 | 内容 |
| --- | --- |
| `wasm/` | 组件编译缓存 |
| `catalog/` | 注册表响应缓存 |
| `diagnostics/` | 导出的诊断包 |

日志位于数据根目录，不在缓存根目录。诊断导出是明确的文件产物，
分享前请核对实际内容。

## 备份与移除

复制或移除配置目录前退出宿主。
保留设置、设备关系和插件数据时，备份数据根目录；删除后会丢失这些本机状态，需要重新配置。

不要只凭目录名像旧缓存就删除。
相对路径只有结合所属宿主配置才有明确含义。
