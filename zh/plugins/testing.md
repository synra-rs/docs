# 测试

校验真正准备安装的包，再在真实宿主中走完用户流程。

## 包校验

```sh
synra-plugin build
synra-plugin verify --dir dist
```

| 检查 | 能证明 |
| --- | --- |
| 清单 | 字段与约束可解析 |
| 组件 | 实际字节实现必需的 WIT ABI |
| 导入 | 宿主函数导入具有有效声明 |
| UI ZIP | 入口、路径、大小、重复项与归档完整性符合要求 |

缺失或无法读取的文件会失败。Verify 通过不代表业务行为、跨设备交付或操作系统效果已经验证。

## 逻辑与页面检查

在无宿主环境测试纯解析、决策或手势识别。
通过模拟客户端检查页面的等待、拒绝、取消、错误与迟到响应。
模拟数据保持真实序列化形态：协议会省略的可选字段，在夹具中也应缺省。

SDK 的真实宿主导入需要组件宿主，原生单元测试不能替代。

## 宿主集成

安装实际包，明确批准、启用、打开页面并调用动作。
通过生产 RPC 和真实 Wasm 检查身份、范围授权及拒绝路径。

双设备功能同时驱动两端，确认拒绝或取消不会产生效果，
停止和撤权会释放持续任务。

## 实体设备验收

| 环境 | 能证明 |
| --- | --- |
| 浏览器预览 | 布局与浏览器交互 |
| 回环 TCP | 双端传输和协议行为 |
| 记录型平台适配器 | 原生边界上的命令及清理 |
| 实体手机与电脑 | 返回、触控、原生效果和实测性能 |

记录实际运行了哪些层次，不要把记录适配器当成真实鼠标验收。
