# Synra 是什么

Synra 通过插件让设备协作。软件本体管理设备、权限和任务，插件提供具体功能的页面与逻辑。

## 可以做什么

- 在局域网发现并配对设备。
- 从本地目录或已配置的注册表安装插件，确认、启用、更新并同步。
- 打开插件页面，选择要协作的设备。
- 处理请求，查看任务结果和诊断日志。

例如，Touchpad 插件让手机在电脑同意本次连接后控制 Windows 鼠标；
Starter 演示本地诊断和明确的目标选择。

## 各部分如何协作

| 部分 | 职责 |
| --- | --- |
| 应用 | 设备与插件管理、确认对话框、设置和页面承载 |
| Rust 内核 | 发现、配对、连接、任务、传输和插件执行规则 |
| JS 库 | 客户端与协议类型、测试工具和共享主题 |
| 插件 | 使用已声明宿主能力的业务页面与逻辑 |

两端都是宿主，但原生能力因平台而异。选择接收设备前，请查看[平台支持](/zh/reference/platform-matrix)。

## 当前边界

Synra 处于开发阶段。开发流程已产出 Windows 和 Android ARM64 构建；
这不表示所有系统都有商店渠道或正式版本。分享、剪贴板工作流和远程动作取决于已安装插件及宿主已实现的接口。

::: warning 在可信局域网使用
当前设备通信使用明文 TCP。配对码用于人工核对本次请求，不加密流量，也不提供密码学设备身份认证。
:::

内核不要求云端账号。插件访问外部服务，需要通过其声明并获准的宿主能力。
