# 快速上手

从两个运行中的宿主和一个已安装插件开始。本页介绍当前设备与插件流程，
不假定主程序内置分享或剪贴板功能。

## 1. 准备两台设备

在可互通的同一局域网运行匹配构建。移动端 Synra 保持前台。
可用的安装方式见[安装](/zh/guide/installation)。

## 2. 配对

1. 打开“设备”，扫描并选择另一台设备。
2. 发起配对，两端显示同一组六位码。
3. 核对配对码。发起端保持等待且可取消；接收端可以同意、拒绝或拉黑。
4. 在接收端同意，两端显示配对完成。

::: tip 等待明确决定
发现设备或连接成功不会完成配对，接收端必须明确同意本次请求。
:::

## 3. 安装并确认插件

打开“插件”，从包文件或文件夹安装。查看能力声明，批准所需权限，再启用插件。
不请求能力的插件也需要明确“允许运行”。

跨设备功能需要在相关宿主安装匹配插件，也可从插件管理操作中选择“同步到设备”。
留意接收端确认，并在接收后检查权限。

## 4. 打开插件

选择“打开”，按插件自己的页面操作，明确选择目标。
即使设备已配对，部分操作仍需要目标设备单独同意本次请求。

| 插件 | 可以尝试 |
| --- | --- |
| Starter | 查看宿主信息，选择一台已配对电脑 |
| Touchpad | 从手机连接，在 Windows 同意本次会话，再滑动或点击触摸区域 |

Android 通过宿主原生返回栏或系统返回回到主程序；桌面可关闭插件窗口。

## 遇到问题时

依次检查：设备在线、相关宿主已安装插件、权限已批准、插件已启用、本次请求已同意。

发现日志与连接失败说明见[故障排查](/zh/guide/troubleshooting)。
