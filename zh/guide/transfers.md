# 任务与传输

宿主提供传输与通用任务控制。插件决定发送什么内容，以及怎样才算业务完成。
主程序没有开启通用剪贴板镜像的设置。

## 发起任务

具体功能从插件页面发起，宿主可以显示目标、进度、确认和结果。
插件同步从插件管理中发起。

请求入队或发送字节，不等于接收端业务执行成功。请等待对应的任务结果。

## 接收文件

| 阶段 | 接收端行为 |
| --- | --- |
| 提议 | 检查元数据，按要求等待用户决定 |
| 传输 | 将有界分块写入临时存储 |
| 检查 | 核对大小和摘要 |
| 提交 | 放置完整文件并报告结果 |

接收端可同意或拒绝传输。设置中可以管理记住的发送方偏好；
忘记设备也会移除关联的接收信任。

::: tip 等待完成
进度行出现不表示文件完成。请使用已完成任务给出的位置，不要从发送方文件名猜测路径。
:::

## 取消与中断

取消会结束当前任务，并清理尚未完成的接收状态。
断连可能导致失败或需要重新请求；当前版本不承诺任意网络中断或移动端后台中断后自动暂停续传。

重试前检查结果，尤其是只应执行一次的业务操作。

## 剪贴板工作流

剪贴板读写和远端内容处理取决于插件及平台支持。
文字传过去，不表示已在另一台设备粘贴或写入剪贴板。
主程序没有“设置 → 剪贴板”的内置开关。

## 数据保存位置

宿主使用自己的私有数据目录和 inbox 保存接收文件。
实际位置见[数据位置](/zh/reference/paths)及已完成任务。
