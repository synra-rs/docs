# Synra Docs

The website and user documentation for [Synra](https://synra-app.dev), a plugin-based framework for cooperation between devices.

## Read the documentation

| Section | For |
| --- | --- |
| [Guide](https://synra-app.dev/guide/introduction) | Installing a development build, pairing devices, managing plugins and troubleshooting |
| [Plugin authoring](https://synra-app.dev/plugins/getting-started) | Building Rust/Wasm plugins and optional WebView pages |
| [Reference](https://synra-app.dev/reference/capabilities) | Capabilities, events, errors, data locations and platform support |
| [简体中文](https://synra-app.dev/zh/) | The same documentation in Chinese |

The site describes current behavior and its limits. Internal decisions and historical investigations live in the separate [design repository](https://github.com/synra-rs/design-docs).

## Work on the site

Built with VitePress, using the shared Synra theme. Preserve the existing typography and navigation;
use clear sections, short paragraphs, comparison tables and titled containers.

See [CONTRIBUTING.md](./CONTRIBUTING.md) for local preview, bilingual checks, schema checks and the writing guide.
